How a call goes

Each crew member is a plain text file. You paste it into a chat and that chat plays the role.

  1. Paste a crew memberOpen any AI chat and paste one agent file, for example the Scripter.
  2. Paste your briefYour game idea, platform and art style, filled in once in PROJECT_BRIEF.md.
  3. Pass the handoffEvery agent ends with a short handoff note. Copy it into the next chat.

What it won't do

Free means you do the carrying.

  • It doesn't run itself.You pass notes between chats and paste code into Roblox Studio.
  • Free chats forget.Keep your brief and handoff log up to date and paste them at the start of each new chat.
  • AI code has mistakes.Playtest everything, and paste exact errors from the Output window back to the Scripter.
  • Rules change.Read Roblox's current policies on the Creator Hub before you publish or sell anything.
